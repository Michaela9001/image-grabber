产品介绍

选品、做图、存档，
不用再一张张右键另存。

拾图把「看到想要的图 → 保存到本地」之间缩短成两次点击。 它不改变你浏览的网站，也不会把图片发到任何服务器。

01

不打断浏览

悬浮按钮只在你点击时工作，Shadow DOM 把样式与页面完全隔离， 既不会破坏原站布局，也不会被原站样式影响。

02

先预览，再决定

提取结果汇总在独立图库页：网格预览、点击放大、全选或反选， 确认没有遗漏也没有多余之后再下载。

03

统一成 PNG

下载时由后台 Service Worker 解码并重新编码为 PNG， 文件名自动编号，按商品标题归档到「下载/拾图」文件夹。

两种工作方式

传统做法
  • 逐张右键、另存为、改文件名
  • 漏掉懒加载与背景图
  • 混进图标、二维码和占位图
使用拾图
  • 一键提取整页可用图片
  • 自动还原高清原图地址
  • 勾选后批量导出，自动编号

核心功能

从识别到导出，每一步都替你想过。

多来源智能提取

覆盖 img、srcset、懒加载属性、CSS 背景图、 结构化数据与图片链接，尽量不漏掉任何一张商品图。

还原高清原图

识别淘宝、天猫、京东、Amazon 等常见 CDN 的缩略图命名规则， 自动去掉尺寸后缀，优先拿回原始分辨率。

图库集中管理

独立图库页网格展示全部结果，支持全选、反选、单张放大、 新标签打开原图，挑图过程一目了然。

批量导出 PNG

后台统一转码为 PNG，按 001、002… 自动编号并归档。 先应答再后台处理，关闭标签页也不会中断任务。

本地优先

没有账号、没有服务器、没有统计埋点。图片只在本机浏览器与 下载目录之间流动，仅申请完成工作所需的最小权限。

轻量不打扰

悬浮按钮使用 Shadow DOM 隔离，不注入全局样式； 页面加载时不发起任何网络请求，点击前完全静默。

安装步骤

四步完成安装，开始提取第一张主图。

拾图以「未打包扩展」的方式加载，不需要应用商店审核； Chrome 与 Edge 的操作几乎一致。

  1. 01

    准备好扩展文件夹

    下载或克隆本项目并解压，确认根目录中能直接看到 manifest.json、content.js 与 gallery.html。

    提示：选择文件夹时选到这一层，而不是它的上级目录。

  2. 02

    打开扩展管理页

    Edge 地址栏输入 edge://extensions； Chrome 输入 chrome://extensions，然后回车。

    也可以从浏览器菜单 →「扩展」进入。

  3. 03

    加载已解压的扩展

    打开「开发人员模式」开关，点击「加载解压缩的扩展」 （Edge 叫「加载解压缩的扩展」），选择上一步的项目文件夹。

    加载成功后，工具栏会出现拾图的图标。

  4. 04

    到商品页提取图片

    打开任意电商详情页，点击右下角紫色「获取图片」按钮； 在自动打开的图库页里全选或反选，再点「批量下载 PNG」。

    文件会保存到「下载 / 拾图 / 商品标题」目录。

i

更新代码后：回到扩展管理页点击拾图卡片上的刷新按钮， 再刷新已打开的商品页，新的内容脚本才会生效。

隐私说明

只在你的电脑上工作。

拾图没有后端服务。提取到的图片地址保存在浏览器本地存储中， 转码与下载全部在本地完成。

  • 3 项权限 activeTab、downloads、storage，只为完成提取与保存。
  • 0 次上传 不向任何第三方发送页面内容、图片或使用记录。
  • 可随时清空 图库右上角「清空」即可删除本地记录，已下载文件不受影响。

常见问题

可能会遇到的小问题。

有些图片没有被提取到怎么办？

先向下滚动页面让懒加载图片真正出现，再点一次「获取图片」。 部分站点把大图放在需要交互后才出现的浮层里，也可以先打开大图预览再提取。

为什么有少数图片下载成了 JPG / WEBP？

当图片受防盗链保护、无法读取像素数据，或原图体积过大时， 扩展会退回到「直接下载原地址」的方式，并保留正确的文件扩展名， 以保证你能拿到文件。

下载的 PNG 为什么比原图大？

PNG 是无损格式，照片类图片转成 PNG 后体积通常会变大。 如果你更在意体积而不是格式，可以在系统下载目录中再统一转换。

可以在 Firefox 或 Safari 上使用吗？

不可以。拾图基于 Chromium 的 Manifest V3 API（OffscreenCanvas、 chrome.downloads 等），目前适用于 Edge、Chrome 等 Chromium 内核浏览器。
